# Yemen Network & ISP Emulator
مشروع مفتوح المصدر لمحاكاة شبكات الاتصالات (LTE) اليمنية وتغيير هوية مزود الإنترنت.

## المكونات
- **srsRAN:** المحرك الأساسي للشبكة.
- **Python Controller:** واجهة للتحكم في MCC/MNC.

## تنبيه هام ⚠️
هذا المشروع مخصص للأغراض التعليمية في بيئة مغلقة فقط. لا تتحمل أي مسؤولية عن سوء الاستخدام خارج النطاق التجريبي.

## التثبيت
1. قم بتثبيت srsRAN: `sudo apt install srsran`
2. تشغيل واجهة التحكم: `python3 scripts/controller.py`
